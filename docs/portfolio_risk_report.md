# 组合风险诊断报告（① 相关性-aware 组合 VaR）

**窗口**：2018-01-02 ~ 2025-12-31（1858 个交易日，四序列对齐到共同交易日）
**方法**：复用 `risk_metrics.py` 的 Cornish-Fisher 分位 + 协方差矩阵 Σ，对比"忽略相关性的朴素组合 VaR（对角 Σ）" vs "真实组合 VaR（完整协方差）"，量化 inverse-vol 定权隐含的"风险独立可加"盲区。
**数据源**：`data/results/livermore/portfolio_risk.csv`、`alpha_nav.csv`

---

## 1. 相关性矩阵

| | 沪深300 | 价值选股 | 红利低波 | 高股息+成长 |
|---|---|---|---|---|
| **沪深300** | 1.000 | 0.524 | 0.572 | 0.702 |
| **价值选股** | 0.524 | 1.000 | 0.490 | 0.562 |
| **红利低波** | 0.572 | 0.490 | 1.000 | 0.553 |
| **高股息+成长** | 0.702 | 0.562 | 0.553 | 1.000 |

- α 三策略两两平均相关性 **+0.603**（剔除沪深300）
- 含沪深300平均 **+0.567**

**读数**：全部显著为正。α 三策略本质是"A股 价值/红利 权益多头"的三种变体，因子暴露高度重叠——它们不是三个独立赌注，是同一因子穿了三件衣服。

---

## 2. 组合 VaR99 对比（戳 blind spot）

| 权重 | 朴素年化 VaR99（假设 ρ=0） | 真实年化 VaR99（完整协方差） | 相关性税 gap |
|---|---|---|---|
| 等权 | 23.21% | 37.16% | **+60.1%** |
| 逆波动定权 | 21.22% | 34.88% | **+64.4%** |

- 逆波动定权确实把朴素 VaR 压到 21.22%（比等权 23.21% 低，达到"降波动"的表面目的），真实 VaR 也压到 34.88%。
- **但它没有逃脱相关性税**：相对缺口反而更大（+64.4% vs +60.1%），绝对缺口几乎相同（等权 +13.95pp / 逆波动 +13.66pp）。
- **核心结论**：inverse-vol 把多头风险"定价"成好像彼此独立（ρ=0），但真实 ρ≈0.6，真实捆绑风险比它的假设高 **约 2/3**。这正是测度论视频那句"**可加性只对互斥（ρ=0）成立**"的量化实证。

---

## 3. 危机日相关性

- 危机日（沪深300 后 10% 日，约 186 天）平均两两相关性 = **0.603**，仅比全样本 0.567 高 +0.036。
- **含义**：这些策略**平时就已经这么相关**，崩盘时几乎不"更相关"——分散收益被**永久性**削弱，"同时跑三个"的分散化收益有限。
- 对照 ρ=1 角点（各头寸 VaR 直接相加）= 180.31%；真实组合 VaR 37.16% 相对它获得 **79.4%** 的分散收益。注意：这 79.4% 的好处是相对于"完全不分散（ρ=1）"而言；而 inverse-vol 妄图到达的"ρ=0 理想"只给了 21% 的朴素 VaR，现实在 35%，中间差 64%。

---

## 4. 与 P0（α 风险对比）的呼应

- P0 结论：红利低波是唯一"右偏 + 左尾受控"的真 alpha；**价值选股 / 高股息+成长左尾未受控**（CVaR99 ≥ 沪深300）。
- 本报告补刀：**即便把三者组合，也救不了左尾**——因为它们相关性 0.6、崩盘同跌，组合 CVaR 不会比单个好多少。inverse-vol 定权制造了"已分散、已控风险"的幻觉。

---

## 5. 下一步指向

- 若要给 alpha 套风控闸（方向 D / 待办 ⑤），必须用**完整协方差的组合 CVaR** 而非 naive VaR 设闸；
- 且应考虑加入与现有 α **低相关**的资产（国债 / 商品 / 美股）才能真正降相关性税，否则"组合"只是把同一因子的风险再捆绑一遍。
