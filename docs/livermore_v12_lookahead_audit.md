## 2. 锁定的同日未来函数（look-ahead bias）

位置：退出规则"突破后2日不创新高离场"（原文件 line 312-322）：

```python
hold_days = (pd.Timestamp(d) - pd.Timestamp(pos["entry_date"])).days   # 自然日
if hold_days == 2:
    day2_high = high_h_arr[entry_idx+2, ...]   # entry_idx+2 == 当天 i
    if day1_high <= entry_high and day2_high <= entry_high:
        exit_now = True
op = open_raw.iloc[i]   # 用【当天开盘价】卖出
```

买入日 index=e，第2自然日就是当天 `i = e+2`，于是 `day2_high = high[e+2] = high[i]` = **当天的日内最高价**。
它在"当天**开盘**就卖出"的决策里，用了当天收盘后才知道的**日内最高价**。等价于开了上帝视角：
- 当天会创新高（会涨）→ 条件不满足 → **留仓吃涨**；
- 当天不创新高（不涨）→ **提前跑**。

这是完美的日内择时，纯属前视。

## 3. 消融对照：这条规则的"价值"100% 来自前视

用独立审计副本 `run_livermore_v12_audit.py`（含 `--fix-lookahead` / `--disable-failexit` 开关，**默认版跑出 −28.84%，与对方原文件逐位一致**，证明对比干净）：

| 版本 | 总收益 | 最大回撤 | 夏普 | 牛市日 | 熊市日 | 开仓 |
|---|---|---|---|---|---|---|
| **原前视版**（对方原样） | **−28.84%** | −53.01% | −0.200 | −5.01% | −25.09% | 784 |
| **关闭这条规则**（对照） | **−60.52%** | −70.90% | −0.610 | −30.09% | −25.09% | 840 |
| **修掉前视、保留规则** | **−68.58%** | −76.15% | −0.743 | −58.07% | −25.05% | 849 |
| 沪深300（基准） | +13.27% | −45.60% | | | | |

**三条铁证**：
1. **前视贡献 ≈ +32pp**：前视版 −28.84% vs 关闭规则 −60.52%，差距几乎全在**牛市日**（−5% vs −30%），熊市日纹丝不动（−25%）。前视只在"会涨的日子"帮得上忙 —— 这是前视作弊的标准指纹。
2. **这条规则本身是有害的**：正确实现（无前视）时保留它 −68.58%，**关闭它反而 −60.52%（好 8pp）**。它不是"减少假突破的好规则"，是"靠偷看未来才显得好的坏规则"。
3. **真实水平 ≈ −60% ~ −69%**：无任何未来函数时，这个策略 2018-2025 亏 60% 以上，跑输沪深300 约 75~82pp。

- **正确的部分**：突破位/MA/水位线在 hfq(去分红缺口)空间、成交用原始价、市场门控与开仓信号均 T-1 判定 T 开盘执行、NaN 停牌 carry-forward 估值 —— 这些都对。

## 5. 最终判断

- 对方"从 −59.81% 改善到 −0.53%"**不成立**。当前文件真实约 **−28.84%（含前视）→ −68.58%（去前视）**。
- **−59.81% 那版可能更接近真相**（真实甚至更差）。每一次"大幅改善"都伴随一次新的未来函数，这是第 3 次在同一份代码谱系里抓到（前有同日成交 +594%）。
- **核心诊断不变**：20日突破追势信号在 A股**没有 edge**。所有"优化"要么无效，要么就是（有意或无意）引入未来函数把回测刷好看。风控/择时最多减亏，改不出正收益。

**建议**：不要再在这个信号上迭代。若要用利弗莫尔思想里唯一有点价值的东西（市场环境门控），正确用法是把它当**风控闸**，去给真正有 alpha 的策略（价值 / 红利低波 / 高股息+成长）做熊市减负，而不是让"突破"自己当入场信号。
