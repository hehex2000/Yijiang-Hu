# 白话 ↔ 数学：B站视频「散户心法」对照平台落地清单

> 配套任务：#53 三层账户模板 / #54 规则再平衡反事实 / #55 时间成本维度
> 评估基准：视频整体评级 🟢B（公允，无引流、零夸大，方法论可迁移）
> 本文目的：把 UP 主的「口语化道理」逐条翻译成平台已有的数学/代码模块，并标出哪些是平台已做、哪些还需补。

## 0. 一句话结论

视频讲的不是「新 alpha」，而是**风控与行为纪律**——守复利、别追价值陷阱、别用努力掩盖无效操作。这三点平台**已经用数学实现了一大半**（凯利封顶、价值陷阱护栏、dd-stop/VaR），剩下三块（显式三层账户、再平衡反事实、时间成本维度）是「行为纪律的可视化补完」，已建 task 跟踪。

## 2. 三个落地项（行为纪律的可视化补完）

### task #53 三层账户模板（核心/卫星/现金）
- **白话**：大部分钱放核心层长期拿（宽基/红利低波），小部分放卫星层做择时博收益，留现金等坑。
- **数学**：`config.py` 新增 `account_layers` 段（core / satellite / cash 三层权重 + 各自基准），`run_backtest` 输出分层 NAV 与再平衡日志。
- **验收**：20 万组合跑「一层全仓」vs「三层」A/B，确认现金层在回撤期缓冲、卫星层贡献边际 α。

### task #54 规则再平衡反事实对照
- **白话**：月度调仓到底比「买了不动」多赚没？还是只是多交手续费？
- **数学**：复用 `run_monthly_rebalance.py` 引擎，同一股票池下跑 规则再平衡 / 阈值再平衡（偏离±x%才调） / 买入持有 三者的 总收益·年化·换手率·净α 横向表。
- **验收**：直接回答「努力悖论」——多操作是否真多赚。

### task #55 时间成本维度指标
- **白话**：你盯盘、决策花的那些时间，折算成「时薪」值不值？
- **数学**：报告新增「时间成本」行——年化换手次数 × 单次调仓工时 → 收益/工时；与买入持有的极低时间成本对照。落地 `analyze_time_cost.py` + 报告段。
- **验收**：高频策略「时薪」被时间成本显著拉低，证伪「勤能补拙」。

## 3. 反向映射：平台已做、但视频没点破的（我们的增量价值）

视频是「行为心法」，平台已经把它**硬化成可回测、可证伪的数学**，这是视频给不了的东西：

1. **凯利不是口号是代码**：视频说「别满仓」，平台用 `f*=(b·p−q)/b` + 封顶 20% 把它变成每笔交易的硬约束，且 12 个策略已验证封顶生效（55–81% → 16–20%）、回撤收窄 2/3。
2. **价值陷阱护栏可证伪**：视频凭经验说「高股息率可能是陷阱」，平台用三道财务护栏把它写成因子过滤，且能 walk-forward 验证「去掉护栏会不会多赚」——结论是可验证的，不是信仰。
3. **dd-stop 防跨 session 累积亏损**：视频说「亏多就停」，平台用 VaR 反解 + 组合层级 dd-stop 把「停」变成自动触发，不靠人自律。
4. **成本建模真实分科目**：视频朦胧提「手续费」，平台 `calc_fee` 拆 佣金+印花税+过户费+滑点，单笔往返≈0.35%，让「给券商打工」变成可量化的数字。
