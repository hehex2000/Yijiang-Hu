# 经典策略去魅 Checklist（通用评估框架）

> 适用对象：任何「经典交易战法 / 名人投资策略」——Jim 系视频、利弗莫尔、缠论、神奇公式、狗股、红利贵族、尼克·斯利普、巴菲特语录等。
>
> **核心信条**：过滤后的信号，按字面规则是亏钱的；只有补上原版缺失的现代风控，才勉强可用。人物的传记是风控反面教材，不是致富手册。
>
> **一句话判定流程**：转录/读书 → 批判式总结（只验证筛选机制？）→ **实现完整策略 + 多窗口回测** → 去魅结论。
> 任何只给你「漏斗 9775→848 筛掉多少」却不给「筛完后赚不赚钱」的内容，默认打问号。

---

## 1. 时代约束审计（Epoch-Constraint Audit）

任何策略都受其诞生时代的认知约束。先审计，再决定是否值得复刻。

| 检查项 | 要问的问题 | 利弗莫尔判例 |
|---|---|---|
| 市场机制 | 当时有涨跌停 / 熔断 / SEC / 做空 / T+1 吗？ | 1934 前无 SEC、无涨跌停、无现代保证金框架 |
| 风控概念 | 当时有 Kelly(1956) / MPT(1952) / VaR / 正式止损纪律吗？ | 均无；止损是民间经验，非 formalized 学科 |
| 杠杆环境 | 是否依赖无约束 margin？ | 重度 margin = 真正杀手，四次赔光本金的结构必然 |
| 数据后见 | 战法是否依赖今天才有的复权 / 逐笔数据？ | 很多「关键点」靠后见之明才能定义 |
| **原版风险评级** | 照搬原样的风险等级 | **高（时代认知约束，无风控概念）** |

→ 判定：原版受时代约束 ⇒ 必须叠加现代风控才能用，**不可浪漫化人物**。

---

## 2. 盈利能力实证（不是筛选机制验证）

**红 flag**：只展示「筛选漏斗」（如 9775→848 筛掉多少），不展示「筛完之后赚不赚钱」= 筛选机制验证 ≠ 盈利能力验证。标题写「验证」往往是 clickbait。

> **⛔ 审计红线 #0（一票否决）：同日未来函数（look-ahead bias）**
> 任何「用 day-i 收盘价决定 day-i 开盘成交」的回测直接作废。标准约定：**决策只用 ≤ day i−1 的数据，在 day i 开盘执行**（信号 T−1 收盘判定 → T 开盘成交）。
> 识别口诀：进场/出场触发用了 `close.iloc[i]`、`ma_sets[i]`、`bull.iloc[i]` 等「当日」序列，却按 `open.iloc[i]` 成交 ⇒ 自动躲阴吃阳，回撤被压到不可能的低、收益被抬到不可能的高。
> **实测案例**：利弗莫尔策略另一平台版用此 bug 跑出 +594%（MDD −17.59%）；修正为 T−1 信号→T 开盘后，**同参数同交易直接变 −53%**。+594% 100% 是作弊产物。

必须做：
- **完整策略回测**：含买入 + 持有 + 卖出全流程，不能只报入选名单。
- **基准对照**：必须 vs 买入持有（沪深300 / 中证红利等），只报绝对收益无效。
- **杜绝未来函数**：信号 T-1 收盘判定、T 开盘执行；突破位 / MA 用 hfq 空间（`close×adj_factor`）去分红缺口，估值用原始价。
- **参数透明**：视频/书里模糊的参数（「适当调整」「跌破就走」）必须落成可回测的具体数值，否则无法证伪。

## 3. 退出 / 风控压力测试（成败唯一决定因素）

这是去魅的刀刃。多数经典战法在「退出规则」上讲得最虚，而实证表明它决定一切。

- **单层变量扫描**：固定其它层，只换退出规则，看收益跨度。
  - 利弗莫尔实证：同样全四步，紧退出(−76%) → 合理退出 MA60 让利润奔跑(−1%)，**75pp 差距只来自一个退出参数**。
- **分层消融 (ablation)**：仅 X / +Y / +Z / 全四步，逐层展示 P&L 贡献，定位哪层赚钱、哪层拖后腿。
  - 利弗莫尔消融（全周期 2014–2026，紧退出）：仅关键点 −97% → +市场环境 −50% → +板块强度 −97% → 全四步 −76%。
- **强弱市场分段**：牛市日 vs 熊市日收益，验证「市场环境门控」是否真有效。
  - 利弗莫尔（合理退出全四步）：牛市日 +305% 但熊市日 −75.6%，净 −1.25% ⇒ 是「崩盘保护器」非「造富器」。
- **判定**：成败是否高度依赖讲得最虚的退出规则？⇒ 若是，原版不可直接用。

## 4. 独立 alpha vs 风控叠加层

| 维度 | 判定 |
|---|---|
| 纯多头突破在 A 股 | 通常负期望（利弗莫尔仅关键点 −97%） |
| 唯一稳健正贡献 | 「市场环境 / regime 门控」= 现代风控叠加层（持仓 93%→57%、熊市 −54%→−16%） |
| 造富器 or 崩盘保护器？ | 多数经典战法是后者 |
| 实操建议 | 取骨架（市场状态 + 信号），套现代风控（仓位 / VaR / 止损纪律）再实证，不浪漫化人物 |

## 5. 历史人物风险档案（模板）

评估任何名人时，先查其**实盘结局**：

- **利弗莫尔**：四次赔光本金 + 自杀。规则他发明、他自己背叛（抄底摊平 / average down、扛亏损单）。生平 = 风控反面教材，不是 playbook。
- 凡破产 / 清盘 / 长期跑输基准的名人 ⇒ 直接降级其「战法」可信度，无论文笔多好。

→ 反向补刀原则：用户给名人打高评价时，主动补「实盘结局 + 时代约束」一刀。

## 7. 工作流（本框架已验证的 pipeline）

转录 → 批判式总结(模板 B) → **实现完整策略 + 多窗口回测**（仿 `div_growth` / `livermore` 范式）→ 去魅结论。

- 先写独立研究版（多窗口 + 强弱分段）跑通，再接 `backtest/*_plugin.py` 平台插件（`run_backtest.py:load_strategy_plugins()` 自动发现）。
- **关键坑（血泪）**：退出位必须对照**入场时的固定 pivot**，而非当日滚动突破位——否则入场 1–2 天后被判「跌回突破位」清仓，复利归零（利弗莫尔全周期 −76% 的 bug 正源于此，修复后逻辑才合理）。
- pandas 3.0 已移除 `fillna(method=)`，改用 `.ffill()`。
- 性能：主循环避免每日全池(~800 只) `.get(code)` 切片扫描，预计算 numpy 布尔矩阵 + 每日触发集合(`set`)，降到秒级；数据加载仍是主耗时。

## 8. 利弗莫尔判例速查（校准锚）

| 四步 | 实证判定 |
|---|---|
| ① 市场环境（熊市不开仓） | ✅ 唯一正贡献 = 现代风控叠加层，持仓 93%→57%、熊市 −54%→−16% |
| ② 板块强度 | ❌ 负贡献（买在情绪顶，随后补跌） |
| ③ 关键点突破 | ➖ 中性，纯多头负期望 |
| ④ 失效退出 | ⚠️ 成败唯一决定因素，但他讲得最虚、本人也守不住 |

全周期 2014–2026：紧退出全四步 **−76.27%**（超额 HS300 −189%）；合理退出(MA60)全四步 **−1.25%**（超额 −114%）。相对沪深300(+113%) 仍大幅跑输——证明方法是「崩盘保护器」而非「造富器」。
