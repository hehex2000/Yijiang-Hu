## 1. 结论速览

> 🚨 **2026-08-31 重大修订**：补充「随机入场控制组」暴露度对照实验（见 §6.3）后，**OBV 与 %B 的增量被证伪为零 / 负 alpha**。
> 此前基于全样本 A/B 与 walk-forward 给出的正面结论**已作废**——那些增量几乎全部由"交易更多 → 在市时间更长 → 吃到 2019-2026 长牛 beta"解释，与选股 skill 无关。**下表为修订后判定，以此为准。**

| 候选 | 机制 | 全样本 Δ（简单/真实） | walk-forward | **暴露度对齐后的 alpha** | 最终判定 |
|---|--:|--:|:--:|--:|---|
| **Head-fake 假突破过滤** | 闸门（减交易） | −1.53pp / — | — | — | ❌ 证伪（负贡献） |
| **MFI 量能闸门** | 闸门（减交易） | −8.30pp / −7.96pp | — | — | ❌ 证伪（负贡献） |

| **OBV 量能背离** | 额外触发（加交易） | +4.61pp / +3.48pp | 4/5 | **≈ 0.00pp（等于随机）** | ❌ 无 alpha，不采用 |
| **OBV + regime-gate** | — | — | 5/5 | 同左（同为暴露度效应） | ❌ 不作为推荐组合 |

**一句话（修订后）**：四个"视频候选"**全部无真 alpha**。两个闸门类（Head-fake −1.53pp、MFI −8.30pp）直接负贡献；两个额外触发类（%B +1.79pp、OBV +4.61pp）在全样本 A/B 上看似为正，但在**同等入场笔数**下与"随机入场"控制组对比——**OBV 恰好打平、%B 反而跑输**，说明增量 100% 来自长牛 beta 而非信号 skill。

> ✅ **但策略本身是好的（见 §11）**：基线自己的信号（下轨 + RSI 超卖 + 布林带未张开）经**等长随机窗口对照**验证，**确有真 alpha**——它挑中的持仓窗口平均 +4.348%，比同期等长随机窗口 +0.678% 好 **+3.670pp**（6.4 倍）。单笔期望 **+4.19%（净）**、盈亏因子 **2.69**、费率拖累仅 0.158pp/笔。
> **被淘汰的是"增强项"，不是策略本身。** 真问题是产能未用满（7.5 年仅 ~13 笔/只），而非技术不行。

> ⚠️ **方法论教训（可复用，重要）**：任何"额外买入触发"型信号，在上涨样本里都会因增加在市时间而自动增产。
> **红旗 = Δ 与交易数强正相关**（本例：OBV 在 K=5 时 106.4 笔→+5.51pp，K=20 时 74.1 笔→+2.95pp，近乎单调）。
> 此类信号**必须先做暴露度匹配 / 随机入场对照，再谈 alpha**；regime-gate 与 walk-forward **都洗不掉 beta**——本例两者都"通过"了，却依然零 alpha。

> ⚠️ **另一副作用（§7）**：regime-gate 会把基线自己几乎关死（交易 26.6 → 0.6~2.7/窗），使组合实质变成新策略变体。OBV 被证伪后该问题不再构成决策障碍，但仍是使用 `market_regime_gate` 时必须知道的事实。

### 2.1 三道验证关（纪律）

1. **单变量 A/B**：同一脚本内只开关目标变量，其余全同 `config.STRATEGIES["mean_reversion"]`。
2. **两关复核**：① 大盘趋势门控（regime-gate）② 真实分科目成本（real_cost）——确认不是牛市样本内过拟合、且净收益在真实摩擦下仍成立。
3. **walk-forward**：把样本切成 **5 个不重叠 ~18 个月 OOS 窗口**，逐窗复算 Δ，确认增量不是"单期幸运"。

### 2.2 两关的具体口径

- **regime-gate**（`market_regime_gate`）：基准 000300.SH 日线，**t−1 收盘 < MA(60) 则禁止新开仓**。无未来函数。
- **真实成本**（`real_cost`，`base_strategy.py` 第 68/101/108/166/206–207 行）：佣金万 2.5 + 滑点 0.1%（双边）+ 过户费 0.001%（双边）+ **日期感知印花税**（2023-08-28 前 0.1% / 后 0.05%）。关闭时维持原简单口径（佣金万2 + 卖出印花税 0.1% 固定，无滑点/过户费），与历史数字完全一致。

### 6.3 🚨 暴露度对照：随机入场控制组（决定性，推翻本节全部正面结论）

**动机**：§11 参数敏感性扫描暴露了红旗——Δ 与交易数强正相关（K=5 时 106.4 笔→+5.51pp，K=20 时 74.1 笔→+2.95pp，近乎单调）。而基线 C0 仅 26.6 笔（大部分时间空仓）、CO 有 91.3 笔，同期沪深300 涨 **+54.51%**。这强烈提示：增量来自"在市时间更长 = 吃到长牛 beta"，而非入场时点的 skill。

**设计**（`run_mean_reversion_random_entry_control.py`；插件新增 opt-in 开关 `random_entry`，默认关）：
- 与 OBV **完全相同的准入条件**：空仓 + 布林带未张开（`cond_not_widening`）+ 大盘允许；
- **出场逻辑与基线完全一致**：Z>2 或 RSI>70 + 止损，不做任何改动；
- 仅把"何时入场"换成**伯努利随机触发**（概率 p）；
- 扫描 p∈{0.01, 0.02, 0.03, 0.045, 0.06, 0.09} × **3 个 seed 轮次** × 2 种成本 × 40 只，得到"入场笔数→收益"响应曲线；
- 再与 OBV 在**同等入场笔数（38.0/只）**处比较。

**判据（跑前定死）**：OBV ≈ 随机控制组 → 增量全是 beta、无 alpha；OBV 显著 > 随机 → alpha 成立。

| 0.09 | 58.4 | 133.3 | +15.46 | +14.28 | 50.95 | 9.60 | 1.48 |

（简单成本同形：38.8 笔处 +15.50%，29.7 笔处 +14.34%，11.9 笔处 +12.14%）

**对齐 OBV 的 38.0 笔后的关键对比**

| 口径 | 基线 C0 | 随机控制组（38 笔） | OBV 背离（38 笔） | **OBV − 随机 = 真 alpha** |
|---|--:|--:|--:|--:|
| 简单成本 | +10.74% | **+15.40%** | +15.34% | **−0.06pp** |
| 真实成本 | +10.27% | **+13.73%** | +13.75% | **+0.02pp** |

→ **beta 占比 ≈ 99~101%，alpha ≈ 0**。随机入场在同一笔数下拿到与 OBV **完全相同**的收益。

**结论**：**OBV 背离的增量 100% 由"交易更多 → 在市更久 → 吃到长牛 beta"解释，没有任何超越暴露度的选股 skill。** 此前"强 opt-in（真实 +3.48pp）"的结论作废。

**对 %B 的连带判定（更差）**：随机控制组 @29.7 笔 = +14.34%（简单）/ +12.93%（真实），而 %B @31.9 笔 = +12.53% / +11.22% —— **笔数更多却少赚约 1.8~1.9pp，属负 alpha**。故 §4 的"边际 opt-in"结论同样作废。

**为何 regime-gate 与 walk-forward 都没能发现**：两者只检验"增量在子样本/严苛条件下是否稳定"，但**暴露度本身在每个子样本里都被同等放大**，因此 beta 会一路"通过"所有稳定性检验。这是本轮最重要的方法论教训。

## 7. ⚠️ 关键副作用：regime-gate 会关死基线

这是决定"是否进默认"的核心事实，必须明确记录：

| 窗口 | C0s 基线交易/只 | C0gs 基线+gate 交易/只 | C0gs 均值% | C0gs 胜率% |
|---|--:|--:|--:|--:|
| W1 | 4.2 | 1.2 | +1.15 | 25.83 |
| W2 | 4.0 | 2.0 | +0.41 | 32.54 |
| W3 | 6.5 | **0.6** | −0.02 | 10.83 |
| W4 | 6.4 | **0.9** | +0.04 | 15.38 |
| W5 | 6.1 | 2.7 | +0.01 | 27.06 |

**基线的交易数从 26.6/全样本 掉到 0.6~2.7/窗，收益 ≈ 0、胜率仅 10~32%**；而同期 COgs 仍有 7.1~14.9 笔、收益全正。

**含义**：开启 regime-gate 后，**几乎全部交易与全部收益都由 OBV 背离提供**。该组合实质是"OBV 背离 + 大盘择时"的一个**新策略变体**，不是"在原基线上做增量"。

> 原因：A股 2019-2026 期间指数长期处于 MA60 下方，而均值回归本就在"市场低于 MA60 的 Correction 期"最赚钱——门控恰好禁掉了这些最佳买点（此冲突在 %B 报告的 §5.3 已记录）。

**决策后果**：把该组合提为默认 = 把 `mean_reversion` 策略的默认行为整体换掉。这属于平台级行为变更，**未执行**，保持 opt-in，待用户明确拍板。

  5. **OBV + regime-gate**：walk-forward 5/5 曾被当作稳健证据，实为同一暴露度效应 → **不作为推荐组合**。
  6. **净结果**：四个视频候选**全部淘汰**；`mean_reversion` 策略维持原默认行为，不做任何改动。

## 11. 基线单笔期望与窗口 skill 验证（正面结论：基线本身有真 alpha）

前述实验淘汰了四个"增强"候选，随之浮出一个更重要的问题：**这套策略本身的期望到底如何？**
（脚本 `run_mean_reversion_trade_expectancy.py`：FIFO 配对 round trip，`buy.cost` 含费、`sell.revenue` 扣费后；并用**等长随机窗口对照**检验时点 skill。）

### 11.1 单笔期望（533 笔平仓对，净口径含手续费/印花税）

| 指标 | 值 |
|---|--:|
| 平仓交易对数 | 533 |
| 胜率 | **62.66%**（334 胜 / 199 负） |
| 平均盈利 / 平均亏损 | +10.65% / −6.66% |
| 盈亏比（avgW/\|avgL\|） | 1.60 |
| 盈亏因子（ΣW/\|ΣL\|） | **2.69** |
| **★ 单笔期望（净）** | **+4.189%** |

| 费率拖累 | **仅 0.158pp/笔** |
| 中位（净） | +3.790% |
| 平均持仓 | 25.4 交易日（中位 20 日） |

### 11.2 持仓窗口随机对照（决定性）

对每笔真实交易（持仓 h 日），在同一只股票的回测区间内随机取同样长度 h 的窗口（30 次采样），比较收益：

| | 平均收益 |
|---|--:|
| 策略实际选中的窗口 | **+4.348%** |
| 等长随机窗口 | +0.678% |
| **差（时点 skill）** | **+3.670pp** |
| 单笔优于随机的比例 | 60.2%（纯随机预期 ≈ 50%） |

→ ✅ **基线（下轨 + RSI 超卖 + 布林带未张开）的入场信号确有真 alpha**：它挑中的持仓窗口比"在同期随机持有一段"好 **6.4 倍**。

**这与四个候选形成鲜明对照**：OBV/%B 的额外交易是纯 beta（等于/跑输随机），而**基线自己的信号是真 skill**。被淘汰的是"增强项"，不是策略本身。

### 11.3 由此暴露的真问题：产能严重未用满

- 7.5 年间仅约 **13.3 笔/只**（533 / 40），绝大多数时间资金闲置；
- 而单笔期望 **+4.19%**、费率拖累**仅 0.158pp/笔** → **对交易成本极不敏感，产能远未用满**。

→ 瓶颈是**机会太少**，不是技术不行、也不是成本太高。若要提升收益，正确的杠杆是**提高部署度**（放宽阈值 / 多标的并行 / 显式仓位管理），而不是引入已被证伪的信号。

> ⚠️ 统计口径提示：533 笔并非独立同分布（同股、同时段、窗口重叠），显著性不宜按朴素标准误解读。但效应量很大（6.4 倍）且方向高度一致，结论方向可信。
