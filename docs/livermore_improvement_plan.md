> 审计基线：原版 2018–2025 全四步 **−31.22%**（已剔除同日未来函数作弊；作弊版 +594% 见 `livermore_lookahead_audit.md`）

## 1. 核心诊断：不是退出规则问题，是信号没有 edge

把快/慢门控两张表拼起来，病根暴露无遗：

| 版本 | 总收益 | 牛市日 | 熊市日 |
|---|---|---|---|
| 慢门控（现状） | −39.94% | −36.98% | −4.70% |
| 快门控（新） | −42.90% | −20.10% | −28.54% |

**这个策略在牛市和熊市都亏钱**（牛市 −20%~−37%，熊市 −5%~−28%）。这不是"止盈太早/止损太慢"能救的——这是**入场信号（20 日突破 + 量能 + 板块强度）本身在 A 股 2018–2025 是负期望**。

朴素趋势突破在 A 股是被摩擦成本吃光的一类策略：
- 低胜率（~33%）+ 趋势没拿住 = 典型的拥挤追势脸；
- 2018–2025 两个大回撤（贸易战、2022 杀估值）恰是最不利环境；
- 板块强度（买动量最强）本质是"买在情绪顶、随后补跌"，我早前的全周期消融已证明它是**负贡献**。

**所以方向很清楚：别在退出参数上绣花，要从"信号质量"和"风险预算"两端动刀。**

## 2. 改进方向（按性价比排序，全部非参数挖掘）

### 方向 A —— 去掉"板块强度"负贡献，换成低波筛选（最高优先级）
- **证据**：全周期消融显示 `+板块强度` 比 `仅关键点` 还差；它专挑近期最强股=买在情绪顶。
- **改法**：默认关闭动量前 30% 筛选，改为**低波筛选**（个股 20 日已实现波动率处于全市场底部 30%）。低波异象是学术界与实务都站得住的正因子，且直接攻击"假突破平均亏太多"——高波动名字既最爱假突破、也更爱反转。
- **开关**：`--sector-mode {momentum, lowvol, none}`，v2 默认 `lowvol`。

### 方向 B —— 波动目标仓位（风险平价-lite，逆波动定权）
- **证据**：亏损交易平均 −3.96%~−4.38%，但少数高波动亏损者吃掉大部分回撤。等权让高波动名字占同样仓位，等于给最易崩的票等额子弹。
- **改法**：新开仓时按 `1/已实现波动率` 在当前空位间分配预算（高波少配、低波多配），总新开金额仍 ≤ 等权预算，不放大杠杆。直接压低高波动失败票的拖累、让低波赢家多跑。
- **开关**：`--vol-size`（默认开），风险预算 `--risk-per`（默认 0.02）。

### 方向 C —— 高波动体制跳过（市场波动率破顶不新开）
- **证据**：快门控实验证明"多交易"会放大亏损；反过来，"少交易最坏段"才有用。突破策略在**市场波动率破顶**（急跌/震荡）时失败率最高。
- **改法**：沪深300 的 20 日已实现波动率超过其过去 250 日 90 分位时，暂停新开仓（持仓照常按原规则退出）。这是**体制叠加层**，不是改信号，不会引入未来函数（阈值只用历史窗口）。
- **开关**：`--vol-skip`（默认开）。

### 方向 D（架构级，超出单脚本范围）—— 降维为"风控叠加层"
- 利弗莫尔四步里唯一有点价值的是**市场环境门控**（步骤①）。正确用法是把它当风控闸，去给**真正有 alpha 的策略**（你的价值选股 / 红利低波 / 高股息+成长）做熊市减负，而不是让它自己当入场信号。
- 这一步需要跨策略改造，不在本脚本内，列为后续方向。

## 3. 反模式警示（务必记住）
- **不要在退出参数上做同窗口参数挖掘**：量能阈值 1.5→2、止盈 12%→15%、止损 5%→3%……在 2018–2025 上一个一个调优 = 过拟合，实盘必回吐。本计划所有改动都是**结构性**（换因子/换仓位/换体制），不是调数字。
- **不要用同日未来函数伪造收益**：day-i 收盘决定 day-i 开盘成交 = 一票否决（见 `livermore_lookahead_audit.md`）。所有信号严格 T-1 收盘判定、T 开盘执行。

## 5. 回测结果（由 `run_livermore_v2.py` 实跑，原文件全程未改）

> 口径：同一 v2 代码内对比（基线 = 动量板块强度 + 等权 + 无波动跳过；改进 = 低波筛选 + 逆波动定权 + 高波动体制跳过）。
> 注意：v2 副本的牛熊门控为 20 日线快速版（并发编辑期间被套用），故 v2 基线(−48.5%) 比用户原 −31.2% 更差；**改进幅度在"同一代码"内对比才有效**。

| 窗口 | 基线(动量筛选) | 仅低波筛选 | 全改进(低波+波动定权+波动跳过) |
|---|---|---|---|
| 2018–2025 总收益 | **−48.52%** | −21.94% | **−17.47%** |
| 2018–2025 年化 | −7.97% | −3.05% | −2.37% |
| 2018–2025 最大回撤 | −57.11% | −35.35% | −47.70% |
| 2018–2025 夏普 | −0.434 | −0.296 | −0.094 |
| 2018–2025 牛市日 / 熊市日 | −30.4% / −26.0% | −10.1% / −13.2% | **−0.4% / −17.1%** |
| 2018–2025 超额HS300(+13.27%) | −61.8pp | −35.2pp | −30.7pp |
| 2014–2017 OOS 总收益 | −37.25% | — | −17.48% |
| 2014–2017 OOS 超额HS300(+73.60%) | −110.9pp | — | −91.1pp |

### 结论
1. **改进有效，但只减亏不翻盘**：全改进版把 8 年亏损从 −48.5% 收窄到 −17.5%（样本内 +31pp、样本外 +20pp），仍是显著负收益，跑输买入持有沪深300（+13%）约 31pp。
2. **最大单因子贡献 = 把"动量板块强度"换成"低波筛选"**（−48.5%→−21.9%，单因子 +26pp）。动量筛选专挑近期最强股=买在情绪顶，熊市补跌最狠；低波筛选在 2018/2022 两次熊市抗压明显更好。**这推翻了我早期仅看 2020–2021 牛市的误判**（那一段低波确实跑输动量，但全周期低波胜出）。
3. **波动跳过 + 逆波动定权**进一步把亏损从 −21.9% 压到 −17.5%，机制是少参与高波动应激段、高波动赔钱票少配。
4. **仍无法扭亏** → 再次确认核心诊断：**信号本身（20日突破追势）在 A 股无 edge**，改进只是把"崩盘保护器"做得更温和，不是把它变成"印钞机"。

### 顺带修复的致命 bug（影响 ALL 配置，含用户原版）
回测中发现估值漏洞：持仓股在**停牌/数据缺失日** `close_raw` 为 NaN，原代码直接把它从净值里丢弃 → 当日净值被打到"仅剩现金"（如 99 万→323 元），制造 **−99.97% 假回撤**。该 bug 在用户原版同样存在，意味着其报告的 −31.2% 总收益虽真，但 −56.91% 回撤在缺失日可能略有失真。
修复：缺失日**沿用最近已知收盘价**（carry-forward `last_close`）估值；成分股退出时同理用 `last_close` 平仓。修复后净值曲线平滑，假回撤消失。
