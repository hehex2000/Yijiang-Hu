## 一、结论（先行）

**§七 的建议得到验证，且是第一个在个股层同时提升 Sharpe 与 Calmar 的方案——但只在其"指数解锁"形态下成立。**

| 关键对比（overlay=OFF，同基线 +228.15%） | 回撤改善 | 收益代价 | \|Eff\| | Sharpe |
|---|---:|---:|---:|---:|
| 非锁存移动止盈 15%（上一份报告最优档） | +13.14pp | **124.04pp** | 0.106 | 0.41（**Δ−0.02**） |
| **锁存 20% + 沪深300 MACD 解锁**（本报告最优档） | +8.22pp | **21.42pp** | **0.384** | 0.51（**Δ+0.08**） |

- **代价只有移动止盈的 1/5.8，却买到其 63% 的回撤改善 → 代价效率高 3.6 倍**；
- Sharpe **反向**：移动止盈 0.41（低于基线 0.43），锁存+指数解锁 0.51（高于基线）；
- 但 `|Eff| = 0.384 ≪ 1`，按"每牺牲 1pp 收益换回的回撤削减"这一严格口径**仍不算划算**——
  划算与否取决于优化目标：**优化 Calmar/Sharpe 则有效，追求绝对总收益则仍付 21pp 代价**。

**三档解锁的排序极其分明（这是本报告最有操作价值的发现）：**

| 解锁方式 | 收益代价 | \|Eff\| | Sharpe | 判定 |
|---|---:|---:|---:|---|
| **none（永不解锁）** | 198–234pp | 0.11 | −1.06 ~ 0.01 | ❌ **灾难**：平均持仓仅 0.38–1.26 只（基线 10.68） |
| **index（沪深300 MACD）** | **21–29pp** | **0.27–0.38** | **0.50–0.51** | ✅ **唯一有效**：Sharpe/Calmar 双升 |
| **stock（个股自身 MACD）** | 72–79pp | 0.08–0.14 | 0.39–0.41 | ⚠️ 无效：个股 MACD 假信号多，频繁进出 |

> 一句话：**个股级保护若非做不可，用「锁存 + 宽基指数 MACD 金叉解锁」；绝不能用无解锁的纯锁存；
> 用个股自身 MACD 解锁会退化成"高频假信号版移动止盈"。**

## 二、方法（与移动止盈同基线、同口径，可直接对比）

### 持仓与基线 = 与上一份报告完全同源
- 选股明细：`bt_quality_sel_OFFICIAL_OFFICIAL_COMPACT_all_12_20130101_20260903.csv`
  （official_compact · 全A · 股息率加权 · **TOP12 · 52 个调仓期 · 140 只股票**）
- 基线 = 引擎自身 `run_nav_weighted()`（零改造真值）；**重放 vs 引擎落盘 NAV 最大差 = 0.000（PASS）**
- 窗口 **2013-01-01 ~ 2025-12-31**（3157 交易日）；复权 hfq 含分红再投；成本/现金约束/差额再平衡与引擎逐位一致

### 锁存掩码 = 逐股复制组合层 `decompose_trail_ab.locked_stop` 状态机
```
hit[i] = close[i] < cummax(close[0..i]) × (1 − thr)
逐日： if hit[i]: s=True ; if golden[i]: s=False ; stopped[i]=s ; mask = ~stopped
```
⚠️ 判定顺序与组合层**逐位一致**：同一日既触锁又出现金叉 → **金叉优先**（解锁）。

两处为锁存语义所做的必要改动（相对 `individual_trail.run_nav_weighted_trail`）：
1. **再平衡日对锁存股跳过建仓**（而非"买了再立刻卖"）——否则每期为锁存股白付一次双边费用，把成本算到止盈头上；
2. **回场只回补"确实被止盈踢出去"的个股**（`stopped` 集合），不回补因整手取整/现金约束没买满的票——
   否则 `thr→∞` 时也会额外建仓，自证失败。

### 自证与可信度
| 验证项 | 结果 |
|---|---|
| `thr=∞` 自证（掩码恒 True ⇒ ≡ 基线） | 最大差 **0.00e+00 → PASS** |
| 重放 vs 引擎落盘 NAV（overlay OFF） | 最大差 **0.000 → PASS** |
| 落盘 CSV 反算 总收益/最大回撤 vs 内存指标 | **全部逐位吻合**（差 ≤3.6e-15） |
| **确定性双跑（同参两次独立进程）** | **逐位相同，最大差 0.00e+00 → PASS** |

### 读表
- **none（无解锁）**：回撤确实砍到 −11.8%（改善 26pp），但**平均持仓只剩 0.38 只 / 12 只**——
  96.5% 的资金长期闲置，总收益 −5.79%、Sharpe −1.06。
  → **在个股层以更极端的形式复现了组合层 B15 的"永久踏空"结论**：锁存无回场机制 = 结构性缺陷。
- **index（沪深300 MACD 解锁）**：回撤改善 6.5–10.4pp，代价仅 21–29pp，**Sharpe 0.50–0.51 全部高于基线 0.43**，
  Calmar 0.286–0.321 全部高于基线 0.253，波动率从 17.57 降到 13.5–13.9（**−21%**）。
  → 唯一在风险调整维度**全面改善**的方案。最优档 **20%**（代价最低 21.42pp、`|Eff|` 最高 0.384）。
- **stock（个股 MACD 解锁）**：回撤改善与 index 相当（5.9–10.8pp），**代价却是其 2.7–3.7 倍**（72–79pp），
  Sharpe 0.39–0.41 反低于基线。→ 个股 MACD 在低波动红利股上假信号过多，频繁进出把 alpha 磨掉。

### 为什么 Sharpe 升而 `|Eff|` 仍 ≪1？
两者度量不同，并不矛盾：
- `|Eff|` 只看 **最大回撤 vs 总收益**（21pp 收益换 8.2pp 回撤）；
- Sharpe 看 **收益 / 波动率**：锁存把波动率从 17.57% 压到 13.75%（**−21.7%**），
  降幅大于收益降幅（21.4/228 ≈ **−9.4%**），所以风险调整后反而变好。
- **结论取决于优化目标**：追求 Calmar/Sharpe → 采用；追求绝对总收益 → 不采用。

**锁存 20% + 指数解锁 vs 移动止盈 15%（各自最优档）**
- 回撤改善 8.22pp vs 13.14pp → 买到其 **63%**
- 收益代价 21.42pp vs 124.04pp → 只花其 **17%（1/5.8）**
- `|Eff|` 0.384 vs 0.106 → **效率高 3.6 倍**
- Sharpe **+0.08** vs **−0.02** → 方向相反

机制解释（为什么锁存优于非锁存）：
1. 非锁存移动止盈在**正常小幅回撤**就离场，低波动红利股回撤频繁 → 反复割肉又追高；
2. 锁存**离场后不再自动回场**，避免在下跌途中反复接刀，只等趋势信号（宽基金叉）确认才回来；
3. 用**宽基指数**而非个股做解锁信号，等于给个股保护加了一层"只有当大盘转好才回来"的纪律，
   滤掉了大量个股级假信号——这正是 `stock` 档失效、而 `index` 档有效的原因。

## 六、⚠️ 本轮发现并修复的非确定性 bug（对主线⑨有直接价值）

**现象**：同一条命令、同一参数，三次独立运行得到三个不同结果：
`index15` 总收益 = **+201.32% / +202.38% / +205.55%**（极差 4.2pp）；
而基线始终 +228.15%、`thr=∞` 自证始终 PASS。

**根因**：回场循环 `for code in list(stopped)` 遍历 **Python `set`**。
Python 字符串哈希默认按进程随机化（`PYTHONHASHSEED`），**`set` 迭代顺序跨进程不保证一致**；
当现金不足以买回当日全部待回场个股时，**"谁先买到"取决于迭代顺序** → 同参不同结果。

**佐证**：`none`（永不解锁）三次数值**完全相同**——因为没有回场就没有现金竞争，
反过来确认了触发条件是"多只同时回场 + 现金约束"。

**修复**：`for code in list(stopped)` → `for code in sorted(stopped)`（已在代码中注释标红）。

**验证**：修复后同参两次独立进程运行 **逐位相同，最大差 0.00e+00**。

> 📌 **通用排查要点**：回测中任何 `set` 迭代 + 资源约束（现金/仓位/并发上限）的组合都是非确定性温床。
> `individual_trail.py`（非锁存）之所以稳定，是因为它遍历的是**已排序的 list**而非 set。

## 八、建议

1. **个股层保护若要上，用「锁存 20% + 沪深300 MACD 金叉解锁」**——代价效率是移动止盈的 3.6 倍，
   且是唯一让 Sharpe（0.43→0.51）与 Calmar（0.253→0.304）同时改善的方案；
2. **绝不能去掉解锁机制**：纯锁存会把平均持仓打到 0.38/12 只，收益归零、Sharpe −1.06；
3. **解锁信号用宽基指数，不要用个股自身 MACD**——后者代价是前者的 2.7–3.7 倍且 Sharpe 反降；
4. **明确优化目标再决定用不用**：追求风险调整收益 → 采用；追求绝对总收益 → 仍要付 ~21pp 代价，不采用；
5. **注意实盘行为改变**：平均持仓 6.8/12 只，约 35–40% 仓位长期为现金，需评估资金效率与心理承受；
6. **下一步可做**：把锁存+指数解锁与**组合层 A15**（组合级锁存15%+MACD）做叠加/互斥对照，
   确认两层保护是否有增量，还是同一 alpha 的重复表达。
