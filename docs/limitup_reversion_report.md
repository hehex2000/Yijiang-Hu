> 验证结论：**355% 被证伪；主拍板配置系统性负 edge；存在微弱正信号但证据不足，无保留/实盘价值**

## §1 结论先行（一句话）

用平台真实全 A 数据（2016–2026，宽成本建模）独立还原后，**视频 355%/14% 完全不可信**；
我们拍板的主配置（N=20 首板 + 低开 3–4% + 60 天位置<50%）实测 **−31.23%**；
参数网格 8 组合里只有 2 个微弱正收益（年化 ≤+1.6%、笔数 ≤77），且存在**网格挑选偏差**与**小样本噪声**，
**不足以支撑任何实盘或策略保留**。

## §5 诚实结论

1. **视频 355%/14% 被证伪**：宽成本日线近似下，主配置 −31%；即便挑出网格里最好的组合也只有 +17.55%（年化 +1.6%、77 笔），与视频差出两个数量级。
2. **主拍板配置（N=20 首板）明确负 edge**：−31% 总收益、夏普 −0.32、跑输 HS300 达 63pp。
3. **微弱正信号存在但证据不足**：N=1/低开[3,4%) 与 N=20/低开[4,5%) 微弱为正，但（a）笔数少（17–77）、（b）是从 8 格网格里挑出来的（挑选偏差）、（c）宽区间立刻转大幅负、（d）**未做时间外 walk-forward 验证**。因此**不能构成"策略有效"的结论**，最多是"学术上低开 3–4% 对连板后个股有极微弱均值回归迹象"。
4. **建议定性**：与已结案的 band_swing / 缩量回踩 / 缠论同属**无保留价值**，不进策略矩阵、不实盘。可作为"涨停过度反应现象"的一笔负面档案留存。

## §9 最终判定（2026-08-26 用户拍板：判伪 falsified）

**核心推理（用户指出，成立）**：Phase A 出场方案 **A（T+1 开盘盈利即卖，否则收盘卖）本质上已是视频"11:28 盈利早卖锁利"机制的最贴近代理**——二者差异仅在于"开盘 vs 11:28 那一瞬的盈利判定时机"（约 11 点前后的日内时点）。既然这个**已最慷慨还原视频出场机制**的测试仍给出 **−31.23%**，真实策略绝无可能达到宣称的 **+355% / −14%MDD**。

**量纲鸿沟不可弥合**：−31% 与 +355% 相差近 400 个百分点，任何 intraday 出场时点的微调（开盘 vs 11:28）都无法跨越；且三出场 A−B 差仅 **+3pp**，证明"盈利早卖锁利"机制本身贡献微乎其微——视频的超额收益并非来自其声称的出场技巧。

**结论**：策略**判定为伪（falsified）**。不进策略矩阵、不实盘、不推 GitHub。作为"涨停过度反应→次日低开"现象的**一笔负面档案**留存即可（学术上该效应短期确有微弱统计正期望，但被视频以可疑回测+课程漏斗包装，实盘与回测差距极大，与本平台宽成本实证一致）。

## §10 walk-forward 严验（2026-08-26，用户要求）

**动机**：用户指出 (1) 网格里 +17.55% 的微弱正格 (N=1, 低开[3%,4%)) 恰好命中视频回撤区间，且 (2) 视频回测未必有我们这么长（可能落在某段牛市窗口）。故做严格 walk-forward 排除"幸运子区间/多重比较"假象。

**方法**：全样本 2016–2026 切 8 个滚动折（训练 3 年 / 测试 1 年，滚动 1 年）。每折：仅用 TRAIN 段在 8 格网格选最优 (N,低开区间) → 在紧邻 OOS 段验证（出场 A）。同时把"全局赢家" (N=1,[3%,4%)) **钉死不重选**、逐折测 OOS，看其是否稳健。

**判定（诚实）**：
- `+17.55%`（全样本）是**幸运子区间 + 多重比较**的产物：walk-forward 后诚实 OOS ≈ 0，钉死赢家也仅 4/8 年正、且 **2025 全年 0 笔信号、多数年份仅 2–8 笔**——样本太小、年份依赖极强，不可交易。
- "每折选出的最优参数"在折间剧烈跳变（N 在 1/20 间反复、区间在 [3,4%)/[4,5%) 间跳），是**噪声拟合**而非真信号。
- 与 §9 一致：**判伪不变，且证据更硬**。视频的 +355% 在本平台宽成本、长样本、严格无前视下彻底不可复现；唯一"像视频"的正格在样本外直接归零。
