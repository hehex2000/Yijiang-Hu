## 一、策略核心逻辑

| 维度 | 说明 |
|------|------|
| **理论基础** | 法玛-弗兰奇三因子模型（Fama-French） |
| **超额收益来源** | 小市值公司成长潜力 + 流动性溢价 |
| **适用环境** | 市场流动性宽松（非紧缩周期） |
| **风险点** | 财务造假退市 + 流动性枯竭 + 风格切换 |

## 二、策略框架设计

### 📌 第一步：选股池构建

| 步骤 | 筛选条件 | 目的 |
|------|---------|------|
| 1 | 剔除 ST / *ST / 退市股 | 风控底线 |
| 2 | 市值排名 1001~3000（中证1000+部分中证500） | 聚焦小市值 |
| 3 | 上市满 1 年（避免次新股波动） | 稳定性 |
| 4 | 近 20 个交易日日均成交额 > 1000 万 | 流动性门槛 |
| 5 | 财务健康筛选（"国九条"标准） | 防退市 |

### 📌 第二步：因子打分体系

| 因子 | 权重 | 计算方式 | 说明 |
|------|------|---------|------|
| **市值因子** | 40% | 总市值排名（越小越好） | 核心因子 |
| **动量因子** | 30% | 60日收益率（需>5%阈值） | 配合成交量确认 |
| **成交量因子** | 20% | 20日日均成交额环比增长 | 防假突破 |
| **质量因子** | 10% | ROE + 现金流质量 | 防"垃圾股" |

**动量因子确认规则**：

```python
# 60日动量 + 成交量确认
```

### **📌 第三步：组合构建**

| 参数 | 设定值 | 说明 |
|------|--------|------|
| **持仓数量** | 20~30 只 | 分散非系统性风险 |
| **单票权重** | 等权或市值倒数加权 | 避免集中度过高 |
| **行业分散** | 单行业 ≤ 20% | 防行业黑天鹅 |
| **调仓频率** | 月度或季度 | 平衡交易成本与因子有效性 |

### **📌 第四步：风控规则**

| 风控维度 | 规则 |
|---------|------|
| **止损线** | 单票 -15% 或 组合 -10% |
| **退市预警** | 持仓股票若被实施风险警示，次日开盘止损 |
| **风格切换** | 若沪深300连续20日跑赢中证1000，暂停小市值策略 |
| **流动性监控** | 若持仓股票日均成交额跌破500万，逐步减仓 |

```python
def filter_st_from_db(db_path, trade_date, codes):
    """从数据库查询并过滤ST股票"""
    conn = sqlite3.connect(db_path)
    
    # 方法：通过名称模糊匹配
    query = f"""
    SELECT ts_code
    FROM stock_basic
    WHERE ts_code IN ({','.join([f"'{c}'" for c in codes])})
      AND (name LIKE 'ST%' OR name LIKE '*ST%' OR name LIKE '%退%')
    """
    st_codes = pd.read_sql(query, conn)['ts_code'].tolist()
```

**2. 财务健康筛查** (`src/risk/financial_health.py`)：

```python
def check_financial_health(db_path, trade_date, codes):
    """基于"国九条"标准筛查财务健康股票"""
    conn = sqlite3.connect(db_path)
    
    query = f"""
    SELECT 
        ts_code,
        净资产,
        净利润_TTM,
        经营现金流净额,
        审计意见
    FROM fina_indicator
    WHERE ts_code IN ({','.join([f"'{c}'" for c in codes])})
      AND trade_date = '{trade_date}'
    """
    
    df = pd.read_sql(query, conn)
    conn.close()
    
    # 健康条件
    healthy = (
        (df['净资产'] > 0) &
        (df['净利润_TTM'] > 0) &
        (df['经营现金流净额'] > 0) &
        (~df['审计意见'].str.contains('保留|否定|无法表示', na=False))
    )
    
    return df[healthy]['ts_code'].tolist()
```

**3. 动量因子 + 成交量确认** (`src/factors/momentum.py`)：

```python
def calculate_momentum_with_volume(db_path, trade_date, codes):
    """计算60日动量，并要求成交量确认"""
    conn = sqlite3.connect(db_path)
    
    results = []
    for code in codes:
        # 获取近60日数据
        df = pd.read_sql(f"""
        SELECT trade_date, close, volume
        FROM daily
        WHERE ts_code = '{code}'
          AND trade_date <= '{trade_date}'
        ORDER BY trade_date DESC
        LIMIT 60
        """, conn)
        
        if len(df) < 60:
            continue
        
        # 计算动量
        momentum_60d = (df.iloc[0]['close'] / df.iloc[-1]['close']) - 1
        
        # 成交量确认（近20日日均 vs 前60日日均）
        volume_20d = df.head(20)['volume'].mean()
        volume_60d = df['volume'].mean()
        volume_ratio = volume_20d / volume_60d if volume_60d > 0 else 0
        
        # 信号确认
        signal = (momentum_60d > 0.05) and (volume_ratio > 1.2)
        
        if signal:
            results.append({
                'code': code,
                'momentum_60d': momentum_60d,
                'volume_ratio': volume_ratio,
                'signal': 1
            })
    
    conn.close()
    return pd.DataFrame(results)
```

```python
def select_small_cap_stocks(trade_date, n_stocks=20):
    """小市值选股主函数"""
    
    # 1. 获取中证1000成分股
    codes = get_index_components('000852.SH', trade_date)
    
    # 2. 过滤ST/*ST/退市股（风控底线！）
    codes = filter_st_stocks_by_name(codes)  # 用方法1或2
    print(f"过滤后剩余: {len(codes)} 只")
    
    # 3. 财务健康筛查
    codes = check_financial_health(db_path, trade_date, codes)
    
    # 4. 计算因子得分
    df = calculate_factors(db_path, trade_date, codes)
    
    # 5. 综合打分 + 选股
    df['total_score'] = (
        df['market_cap_rank'] * 0.4 +
        df['momentum_60d'] * 0.3 +
        df['volume_ratio'] * 0.2 +
        df['quality_score'] * 0.1
    )
    
    # 6. 选TOP N
    selected = df.nsmallest(n_stocks, 'total_score')
    
    return selected
```
