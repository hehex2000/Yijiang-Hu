# 利弗莫尔买点的"体积视角"：概率即体积，趋势即质量的迁移

> 测度论把"概率"定义成"给事件集合赋予体积（面积/测度）"。当我们用这枚镜头重看利弗莫尔的买点，会发现他一百多年前的盘感，恰好是在用自然语言描述**概率质量（volume）的分布与迁移**。本文把 P0 / ① / ② / ⑤ 四份实证嵌进这个框架，给出诚实结论：利弗莫尔买点的"体积直觉"是对的，但它在 A 股的可量化复刻救不回——因为体积会迁移，而迁移本身被成本与相关性吃掉了。

## 0. 一句话立场
风险不是一个数，而是一块有面积的不幸。利弗莫尔的整套买点语言（横盘、关键点、最小阻力线、截断亏损），在体积视角下都能翻译成"检测体积坍缩 / 等待质量迁移 / 裁剪左尾面积"。翻译本身成立，但翻译出的策略在 A 股跑不赢——这不是直觉错了，是体积迁移的代价被低估了。

## 1. 概率 = 体积：风险是"一块有面积的不幸"
测度论视角下，所有可能走势构成样本空间 Ω，每个事件 A⊂Ω 被赋予体积 P(A)。"明天跌 5%"不是一个点，而是一块面积；止损线以下的整条左尾，是一块需要被截断的面积。
- 这与我们写 `risk_metrics.py` 的动机一致：VaR 是"从左边数起占 1% 体积处的高度"，CVaR 是"那 1% 体积的平均高度"——都是从体积里切出来的阈值。
- 关键翻转：正态模型把左尾体积画得太薄。实证（2022–2024 真实 NAV）99% VaR 正态 2.98% vs Cornish-Fisher 5.91%——模型低估了约 98% 的尾部体积。利弗莫尔说"利润会自己照顾自己，亏损不会"，正是意识到左尾体积被主观画小了。

## 2. 最小阻力线 = 概率质量的主峰
利弗莫尔的"最小阻力线"（line of least resistance）不是一条线，而是概率质量（volume）最集中的方向。价格沿最小阻力线走，等价于"走势样本空间里，质量最大的那块体积落在该方向"。
- 这就是为什么横盘后"顺着突破方向"才动手：突破方向的 volume 在膨胀，反向的 volume 在萎缩。
- 但体积的"主峰"是事后的。事前的我们，只能看到 volume 在某区间坍缩（盘整），无法预知它往哪迁移。这是利弗莫尔策略在 A 股趋势市"等对了方向、却赚不到"的结构性原因（box 过滤样本内 +11.30% / 样本外 +7.27%，但参数极尖、仅 20 笔、踏空牛市）。

## 3. 横盘压缩 = 体积坍缩；突破 = 质量迁移
- **箱式压缩（box compression）**：价格在一个窄带里来回，等价于概率体积被压进一个狭长区域——分布的"宽度"（方差）骤降。我们 v2 的 `box_width = (hi-lo)/mid` 阈值，就是在检测"体积是否被压扁"。
- **确认突破 = 体积开始迁移**：当价格越过 box 上沿且放量，等价于 volume 从压缩区"跃迁"到新高区域。量能确认（vol > vol_ma5×1.5）是"迁移是真的、不是噪音"的体积证据。
- 风险：坍缩后的突破，volume 也可能往反方向迁移（假突破）。假突破率 58.7%（早期归因）说明：压缩只保证"要动"，不保证"往哪动"。体积的坍缩是确定的，迁移的方向是不确定的——这恰好是测度论"可加性只对互斥成立"的反面：两条迁移路径的体积不能简单相加，因为样本点只能走一条。

## 4. 关键点 = 体积的临界阈值
利弗莫尔的"关键点"（pivotal point，如前期高点）在体积视角下是**密度的临界等值线**——越过它，volume 的重心从"区间内"切换到"区间外"。这与我们闸门里的 `key_level = rolling(max, look).shift(1)` 同构：把前期高点当成 volume 分布的边界。
- 诚实提醒：关键点本身不提供方向概率，它只是"边界被突破"的几何提醒。把它当买卖信号，等于假设"边界两边体积不对称"——这假设在趋势市成立，在震荡市不成立。

## 5. 止损 = 截断左尾的体积
测度论最干净的一句话：**止损不是预测，是几何裁剪**——把左尾那块不幸的体积直接切掉，让它不再计入你的财富分布。
- 这正是利弗莫尔"截断亏损"的数学本质。我们 P0 的 CVaR 分析量化了这块体积：价值选股 CVaR99 = 6.37%（比沪深300 4.61% 还肥），说明它的左尾体积没被有效裁剪。
- 更深一层：截断左尾会同时改变偏度。⑤ 的闸门把组合偏度从 −0.17 拉到 +0.73，正是"切掉左尾体积 → 分布右偏"的直接后果。

## 6. 可加性只对互斥成立：组合层的"体积重叠"
测度论公理：P(A∪B) = P(A) + P(B) **当且仅当 A∩B = ∅**（互斥）。把两条策略的 VaR "相加"，隐含假设它们亏损的事件互不重叠——即相关性 ρ = 0。
- 但我们 ① 的实证：α 三策略两两相关性 0.49~0.56，平均 0.603。它们的"亏损体积"高度重叠（同是 A 股价值/红利权益多头）。
- 逆波动定权下，朴素 VaR99（假装 ρ = 0）= 21.22%，真实（含相关性）= 34.88%，**相关性税 +64.4%**。inverse-vol 把风险"定价"成好像彼此独立，但真实 ρ≈0.6，捆绑风险比它假设的高约 2/3。
- 结论：利弗莫尔买点再好，三件同因子的衣服叠一起，体积重叠让分散化收益被**永久性**削弱。要真降组合风险，须引入与 A 股低相关的资产（国债/商品/美股），而非在同一体积里多开几扇窗。

## 7. 偏度只刻画不对称，CVaR 才是真实左尾
测度论视角下，偏度是分布三阶矩——只描述"不对称的方向"，不描述"尾巴有多厚"。
- P0 实证：价值选股偏度 +0.37（右偏）、红利低波 +0.23（右偏）、高股息成长 −0.20（左偏）。但只有**红利低波**同时满足"右偏 + CVaR99 3.47% < 沪深300 4.61%"——真正的、左尾受控的 alpha。价值选股虽右偏，CVaR99 6.37% 比宽基还肥。
- 一句话：正偏度 ≠ 更安全。偏度是妆容，CVaR 是底子。单看偏度会误判——这是利弗莫尔"两侧都要截断"命题的量化版。

## 8. 状态机视角：时间也是一种体积
把交易日当成样本空间，每个交易日落在 IN（持仓）或 OUT（空仓）状态。体积视角下，"时间体积"在两种状态间分配。
- ② 的实证：OUT→OUT 93.6%、OUT→IN 6.4%、IN→OUT 13.4%、IN→IN 86.6%；**68% 交易日在空仓体积里**，一旦入场平均仅 7.5 日即离场。
- 这其实是利弗莫尔"赚大钱是等待"的体积版：他把绝大部分时间体积押在 OUT 态，只在 IN 体积里下注。问题出在 IN 体积内的"换手成本"——开费 +15.86% vs 关费 +42.82%，**churn 拖累 26.96pp，吞噬毛收益 63%**。等待做对了，但进出太频繁，把 IN 体积里的利润又吐回给了交易成本（左尾体积的另一种形式：摩擦体积）。

## 9. 诚实结论：体积视角下，利弗莫尔策略为什么救不回
把以上拼成一幅图：
- 买点（横盘压缩 + 关键点 + 量能）在**检测体积坍缩**上是对的，但坍缩 ≠ 方向，假突破 58.7% 说明迁移方向不可知。
- 即便方向对，三策略同因子 → 体积重叠 → 相关性税 +64.4%，分散无效。
- 闸门（⑤）能压左尾（CVaR99 −22.5%），但来源是 62% 空仓的"少暴露"，不是聪明择时（最差 1% 日空仓率仅 52.6%，低于整体）——等于把时间体积挪出市场，代价是总收益 −5.8pp。
- 状态机（②）显示利润被 churn 摩擦体积吃掉 26.96pp。
- 而这一切都建立在一个**非确定性**地基上：选股集合迭代顺序受 PYTHONHASHSEED 随机化影响（已修 `sorted(cand)`），不钉种子则同参数结果漂移——体积本身在抖动。

**最终判决**：利弗莫尔买点的"体积直觉"经得起测度论审视，但它在 A 股的**可量化复刻救不回**。能抢救的不是"更好地复刻买点"，而是把它当成**风控闸**（方向 D）——用体积语言说：在组合左尾体积（CVaR）超过宽基时平仓，在体积坍缩且迁移确认时轻仓试探。这把"等待"从选股艺术降级为组合层的体积裁剪纪律。
