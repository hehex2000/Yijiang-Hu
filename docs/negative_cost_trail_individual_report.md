## 一、结论（先行）

**个股级移动止盈在红利低波质量复合（低波动策略）上 ≈ 负交易，与组合层 `decompose_trail_ab` 结论交叉验证一致。**

- 相对「无个股级止盈」基线，移动止盈牺牲 **124–163pp** 总收益，回撤最多只砍 **~13pp**（且 20%/25% 阈值反而**加深**回撤 0.4–4.0pp）；
- 代价效率 `Eff`：10%/15% 阈值为 **−0.08 / −0.11**——**负号是"回撤变浅(改善)"的记法**（因最大回撤以负数存储），其绝对值 = 每牺牲 1pp 收益换回的回撤削减，仅 **0.083 / 0.106pp ≪ 1**，即**极度不划算**；20%/25% 阈值 `Eff` 为正 = **回撤反而加深**，才是真正的负价值；
- 平台止损层的价值 **100% 来自组合层 MACD 择时 alpha**，移动止盈（无论组合级还是个股级）在低波动策略上**无独立贡献**。

> 一句话：**低波动策略上叠移动止盈 = 把长期持有的低波动红利股，按正常小幅回撤反复割肉又追高，净效果是巨额收益损失 + 回撤改善微不足道（~13pp）甚至反而加深。**

### 代价指标（对齐组合层 `decompose_trail_ab` 口径）
```
DD_cut   = 基线最大回撤 − 方法最大回撤   (pp；最大回撤以【负数】存储，故
                                          DD_cut < 0 = 回撤变浅 = 改善
                                          DD_cut > 0 = 回撤加深 = 恶化)
Ret_cost = 基线总收益   − 方法总收益     (pp，> 0 = 牺牲了收益)
Eff      = DD_cut / max(Ret_cost, ε)    (沿用组合层 decompose_trail_ab 的同口径记法)

判读规则（务必按【绝对值】读，不要按符号读）：
  |Eff| = 每牺牲 1pp 收益换回的回撤削减(pp)
  |Eff| >> 1  → 划算（牺牲少量收益换大额回撤改善）
  |Eff| << 1  → 不划算（牺牲巨额收益只换微小回撤改善）
  DD_cut > 0  → 回撤反而加深，真·负价值（此时 Eff 符号为正，属"虚正"，不可读作有效）
```

> ⚠️ 常见误读：`Eff` 为负**不是**"回撤削减为负"，而是"回撤改善了"的记账结果。
> 判断划算与否看 `|Eff|` 是否接近或大于 1，不看符号。

\* 符号约定：`DD_cut = 基线最大回撤 − 方法最大回撤`，最大回撤以**负数**存储 ⇒ **负 = 回撤变浅(改善)、正 = 回撤加深(恶化)**。
   故 10%/15% 的 `DD_cut = −13.55 / −13.14` 表示**回撤改善了 13.55 / 13.14pp**；
   20%/25% 的 `DD_cut = +0.39 / +4.01` 表示**回撤反而加深 0.39 / 4.01pp**（移动止盈在深度回撤段失效：跌破阈值离场后，标的继续下探，回场时买在更低位，净值曲线更差）。

**读表**：
- 10%/15% 阈值：回撤**确实改善** ~13pp（`DD_cut` 为负 = 变浅），但代价是 **124–163pp 的总收益** → `|Eff| = 0.083 / 0.106 ≪ 1`，典型的"为小幅平滑回撤付出巨额收益"。
- 20%/25% 阈值：回撤**没改善反而加深** 0.39 / 4.01pp（`DD_cut` 为正），收益仍牺牲 134–138pp → 彻底的负价值交易。
- 任何阈值下都**无净收益**：要么 `|Eff| ≪ 1`（10%/15%），要么回撤反而加深（20%/25%）。

## 四、与组合层结论交叉验证（核心交付）

组合层 `decompose_trail_ab`（红利低波·低波动基线）结论：**移动止盈 |Eff|≈0.19（每牺牲 1pp 收益仅换回 0.19pp 回撤削减），近似负交易，平台止损层价值 100% 来自 MACD 择时 alpha**。

个股级本回测（同策略、真实持仓）：
- 10%/15% 阈值 `|Eff| = 0.083 / 0.106`（回撤有改善但代价巨大），20%/25% 阈值回撤加深（`Eff` 近 0/虚正）；
- 与组合层 `|Eff| ≈ 0.19` **同量级、且个股级更差（0.08–0.11 < 0.19）** → 个股级结论与组合层**稳健一致**：低波动策略上，移动止盈 ≈ 负交易。

机制解释（为什么低波动上移动止盈无效）：
1. 红利低波质量复合本就是**低波动、低回撤、长期持有**的策略，价格路径"峰回撤"幅度小、频率高；
2. 移动止盈的"峰回撤离场"主要触发于**正常小幅回撤**，导致**频繁离场-回场**：付交易成本 + 踏空复苏早期（与组合层 `regime` 对长期持有类有害的结论同源）；
3. 标的缺乏足够波动空间来提供"止盈后低位回场"的 alpha——这正是高波动策略才有的移动止盈用武之地，低波动策略没有。

## 七、建议
- **不采用**个股级移动止盈作为红利低波质量复合的回撤控制；
- 该策略的回撤控制应继续依赖**组合层 MACD 择时 overlay**（已有 alpha 来源），而非移动止盈；
- 若确需个股层保护，应转向**锁存硬止损 + MACD 金叉解锁**（组合层 A15 方案，已在 `decompose_trail_ab` 验证有正贡献）做对照，而非非锁存移动止盈。
