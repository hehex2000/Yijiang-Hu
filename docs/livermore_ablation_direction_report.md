# 利弗莫尔"方向确认"消融（ablation）报告：体积坍缩触发 × 候选方向信号分桶

> 承接 `docs/livermore_volume_perspective.md` 第 9 节的开放性结论——"坍缩检测对、方向不可知"。本文用一次干净的分桶实验回答：**给体积坍缩触发加上候选方向确认信号，假突破率能否 <50%？净值能否转正？** 若两者都成立，利弗莫尔框架值得重构；否则检测器本身是噪声。
>
> **一句话结论：方向确认真实有效（净值 −16.63% → −3.5%，改善 ~13pp），但强度不够翻正——6 组候选全部净值 <0，判据失败，利弗莫尔独立 alpha 正式判死刑；其中 C1 板块动量、C4 OBV 进入"突破系正面清单"，C2 低波、C5 突破幅度进入负面清单。**

## 0. 实验设计

- **触发（体积坍缩）** = 关键点突破（`close_hfq > rolling(20).max().shift(1)` 连续 2 日站稳）+ 量能确认（`vol > vol_ma5 × 1.5`）+ 横盘压缩（box_len=20, box_width≤0.15）——与 `run_livermore_v2.py` 的检测逻辑逐项对齐，无未来函数（信号 T-1 判定 / T 开盘执行）。
- **分桶**：6 组平行账本（单次数据扫描、每组独立持仓/现金/净值，仅开仓闸门不同，退出规则组间完全一致 → 隔离单一变量）：
  - `control`：仅体积坍缩触发即开仓（现状基线）
  - `C1 板块动量`：个股 5 日动量行业内前 30%
  - `C2 低波`：20 日已实现波动率行业内底部 30%
  - `C3 突破前趋势`：突破前 20 日个股自身收益 >0
  - `C4 量能潮 OBV`：OBV 20 日斜率为正（吸筹方向确认）
  - `C5 突破幅度>1%`：收盘高于关键点 >1%
- **窗口**：20180101–20251231（中证800 成分池，`config.DATA.local_db_path` 口径）。
- **假突破定义**：入场后第 1/2 交易日 `high_hfq` 均未超入场日 `high_hfq`（利弗莫尔"2 日不创新高即失败"的原文规则）。
- **判据**（预设）：某候选组 **假突破率 <50% 且 净值总收益转正** → 方向确认有效，值得重构；否则放弃。

## 2. 判据判定：无一通过

- **假突破率达标**：全部候选组 43.8–45.6% < 50% ✅
- **净值转正失败**：全部候选组净值 <0 ❌（最好 C1 −3.53%）
- **结论：方向确认信号无法救回利弗莫尔独立 alpha。**

## 3. 关键发现

### ① 方向确认真实有效，但强度不够（C1 / C4）
C1 板块动量、C4 OBV 把净值从 −16.63% 收窄到 **−3.5% 左右**（改善 ~13pp），假突破率压到 43.8%——它们不是噪声，是真在砍坏交易。但最好成绩仍为负：方向对也不足以覆盖 churn 摩擦（② 状态机已证 26.96pp 拖累）+ 薄毛收益。这坐实了体积视角结论：**坍缩检测对、方向信号有帮助，但整套在 A 股没有可救的 alpha。**

### ② C2 低波 / C5 突破幅度 是负贡献（负面清单）
两者反而把亏损扩大到 −33%（比 control 差 ~17pp）：在"突破"场景下，低波和"突破幅度大"作为方向确认是**反指**——砍掉了真正的赢家。后续任何 breakout 系策略，这两个信号应排除。

### ③ C3 与 control 逐位一致 → 平行账本自洽性验证通过
突破=创 20 日新高，本身蕴含"20 日收益 >0"，故 C3 过滤条件几乎恒真，结果与 control 完全一致。这个"零效果"恰好证明平行账本实现无 bug——对照组与恒真组完全重合（579 笔 / 44.4% / −16.63%）。

## 4. 口径提醒：44.4% vs 早期 58.7%

本轮 control 假突破率 **44.4%**，与 volume 视角文中引用的 **58.7%** 不同——两者口径不同：
- 本轮：入场后第 1/2 日 high 均未超入场日 high（利弗莫尔"2 日不创新高"原文规则）；
- 58.7%：早期归因用另一口径（如突破后 N 日内收益为负）统计。
- 两者指向同一结论（方向不可知），不影响判定；跨报告对比时需注意口径差异。

## 5. 与 P0 / ① / ② / ⑤ 的闭环

| 模块 | 结论 | 本轮呼应 |
|---|---|---|
| P0（三策略 α/CVaR 对比） | 真 α 存在但左尾未受控 | 命中率仅 33–39%，胜者 CVaR 未改善 |
| ①（组合相关性/VaR） | 相关性税 +64.4%，分散无效 | 单腿即负，组合层无从救起 |
| ②（状态机/churn） | churn 拖累 26.96pp，吞噬毛收益 63% | 方向改善 ~13pp 仍无法覆盖摩擦 |
| ⑤（box+量能闸门） | 闸门压左尾但靠 62% 空仓，非择时 | 触发本身就是该闸门的信号源 |

## 6. 最终裁决

- **利弗莫尔买点作为独立买卖信号：放弃。** 方向确认（甚至板块动量+OBV 双确认）也无法翻正净值，最好组仍跑输中证800 约 18pp。
- **残留价值**：① 体积坍缩检测本身正确（可作为组合层 regime filter 的候选，但 ⑤ 已证其作用机理是"减少暴露"而非"聪明择时"）；② C1 板块动量 / C4 OBV 进入突破系正面清单；③ C2 低波 / C5 突破幅度进入负面清单。
